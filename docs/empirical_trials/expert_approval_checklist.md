# Protocol Decision Checklist

This checklist is intended for the domain expert approving the empirical trial protocol.

## Protocol Decisions

- [ ] **Target Cultivar Selection**
  * *Status:* Awaiting approval
  * *Notes:* Need to specify the exact strawberry variety (e.g., Albion, Chandler).

- [ ] **Maturity / Harvest State**
  * *Status:* Awaiting approval
  * *Notes:* E.g., >75% red color, harvested on day 0.

- [ ] **Primary Shelf-Life Endpoint**
  * *Status:* Proposed for expert review (Options provided in Decision Brief)
  * *Notes:* Must select ONE explicit threshold (e.g., >6% weight loss).

- [ ] **Measurement Method**
  * *Status:* Proposed for expert review (Options provided in Measurement Comparison)
  * *Notes:* Recommend non-destructive weight loss paired with visual decay incidence.

- [ ] **Packaging Specifications (Comparisons)**
  * *Status:* Awaiting approval
  * *Notes:* Need to specify the control packaging and the modified packaging materials to be compared.

- [ ] **Storage Environment (T & RH)**
  * *Status:* Literature-supported
  * *Notes:* Standard cold chain recommendations are 0–1°C and 90-95% RH, but actual trial conditions must be explicitly defined and continuously logged.

- [ ] **Sampling Schedule & Replicates**
  * *Status:* Awaiting approval
  * *Notes:* E.g., measured daily, n=3 replicates per packaging type.

- [ ] **Microbiological Assessment**
  * *Status:* Not yet measurable with available resources
  * *Notes:* Excluded from the initial protocol unless access to a microbiology lab is secured.
